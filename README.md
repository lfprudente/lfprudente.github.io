# lfprudente.github.io

Personal academic page of Leandro F. Prudente (IME/UFG).

- `index.html`: layout, styles, and the About and Students sections.
- `js/publications.js`: the publication list. To add a paper, copy an entry in the right list (`PREPRINTS`, `JOURNAL`, `CHAPTERS`, `THESES`) and edit it. The page groups entries by year in the order they appear.
- `assets/photo.jpg`: profile photo.

The site is plain HTML with no build step. GitHub Pages serves it from the `main` branch.
